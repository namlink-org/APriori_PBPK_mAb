Purpose

This report documents the reduced sparse monkey PK study-design analysis for AUC0-28d, Cmax, and terminal clearance. The analysis compares study arithmetic means with full rich-population arithmetic means using the standard fold error:

fold error = reduced-study estimate / rich-population reference.

The prespecified acceptable interval is 0.5-2.0. Candidate group sizes are 2, 3, and 4 animals per dose group; five-animal groups are excluded from every scenario.

The analysis is predefined for atezolizumab, avelumab, nivolumab, and pembrolizumab. Run 4 top-down estimates and relative standard errors (RSEs) are read directly from the final monkey-model fit. Parameter uncertainty is represented by available RSEs, and 30% interindividual variability (IIV) is specified independently for CL, V1, Q, and V2. A structural parameter fixed in Run 4, and therefore missing an estimated RSE, is assigned a 40% RSE.

parameter_map <- tribble(
  ~Parameter, ~Theta_name, ~Log_parameter,
  "CL",       "cl",        "lcl",
  "V1",       "vc",        "lvc",
  "Q",        "q",         "lq",
  "V2",       "vp",        "lvp"
)

extract_run4_parameters <- function(molecule) {
  fit <- run4_fits[[molecule]]$fit
  estimated_parameters <- names(fit$opt$par)
  rse <- fit$rse_percent

  parameter_map |>
    mutate(
      Molecule = molecule,
      Estimate = map_dbl(Theta_name, ~ unname(fit$theta[[.x]])),
      RSE_percent = map_dbl(
        Log_parameter,
        ~ if (.x %in% names(rse)) unname(rse[[.x]]) else NA_real_
      ),
      Run4_status = if_else(
        Log_parameter %in% estimated_parameters,
        "Estimated",
        "Fixed"
      ),
      IIV_CV_percent = IIV_CV_PERCENT
    ) |>
    select(
      Molecule,
      Parameter,
      Estimate,
      RSE_percent,
      Run4_status,
      IIV_CV_percent
    )
}

run4_parameter_inputs <- map_dfr(MOLECULES, extract_run4_parameters)

stopifnot(

Analysis definitions

For each simulated study replicate, animals are sampled independently within each selected dose group. AUC0-28d, Cmax, and terminal clearance are summarized with arithmetic means. Terminal clearance follows the project-wide PK convention: the terminal slope is selected from consecutive post-Cmax suffixes using the largest adjusted R-squared, AUCinf = AUClast + Clast/lambda_z, and whole-animal clearance is 24 * Dose * 3.5 kg / AUCinf.

The two-dose design uses 0.3 and 10 mg/kg, and the three-dose design uses 0.3, 3, and 10 mg/kg. A design-level endpoint result is within 2-fold only if every selected dose group has a standard fold error between 0.5 and 2.0.

Standard fold-error distributions

The analysis script RunReducedSparsePKAnalysis.R generates the simulation outputs. The report reads those completed outputs rather than rerunning the model during rendering.

Power-style operating characteristics

The y-axis is the fraction of simulated studies for which every selected dose group is within 2-fold for the indicated PK endpoint.
